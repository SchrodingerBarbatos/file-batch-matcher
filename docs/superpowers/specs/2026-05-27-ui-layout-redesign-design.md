# UI排版改进设计方案

## 项目概述

**项目名称**：文件批量匹配复制工具  
**设计目标**：改进UI排版，解决布局拥挤和比例不协调问题  
**设计日期**：2026-05-27  
**设计版本**：1.0

## 当前问题分析

### 主要问题
1. **布局拥挤**：各个区域之间太紧凑，没有足够的呼吸空间
2. **比例不协调**：某些区域太大或太小，整体视觉不平衡

### 现有布局结构
- 上部：左侧路径设置卡片 + 右侧匹配选项卡片
- 中部：图片处理选项卡片
- 下部：左侧按钮+进度+统计 + 右侧日志卡片

## 设计方案

### 方案选择
**采用方案**：经典左右分栏（方案1）

### 整体布局
- **窗口尺寸**：1000×750（比当前900×700稍大，提供更宽松的空间）
- **左侧**：40%宽度，可滚动的设置区域
- **右侧**：60%宽度，固定的操作和日志区域
- **全局间距**：16px

### 左侧滚动区域（设置区）

#### 1. 路径与文件设置（卡片）
- Excel文件选择 + 浏览按钮
- 编号所在列下拉框 + 列数提示
- 源文件夹 + 浏览按钮
- 目标文件夹 + 浏览按钮
- 底部提示信息

#### 2. 匹配选项（卡片）
- 允许的扩展名输入框
- 文件处理方式下拉框（复制/移动）
- 三个复选框：不限制扩展名、递归搜索子文件夹、目标存在时覆盖

#### 3. 图片处理（卡片）
- 启用图片尺寸/大小处理复选框
- 宽、高、最大大小输入框（横向排列）
- 启用格式转换复选框
- 目标格式下拉框

### 右侧固定区域（操作区）

#### 1. 操作按钮区（扁平化）
- 开始匹配并复制（主要按钮，绿色，大尺寸）
- 终止按钮（次要按钮，红色，大尺寸）

#### 2. 进度区（扁平化）
- 进度条（带流光效果）
- 统计信息：准备就绪 / 成功: 0 / 失败: 0 / 跳过: 0

#### 3. 辅助按钮区（扁平化）
- 保存未匹配编号按钮
- 清空日志按钮

#### 4. 运行日志（卡片）
- 日志显示区域（可滚动，等宽字体）

## 视觉设计

### 布局风格
**混合式布局**：主要区域用卡片，次要区域用扁平化

### 颜色方案
- **主色调**：蓝色系（#0078D4）
- **成功色**：绿色（#0EA348）
- **警告色**：红色（#FF2D30）
- **背景色**：浅灰（#F6F8FB）
- **卡片背景**：白色（#FFFFFF）
- **文字颜色**：深灰（#111827）
- **次要文字**：中灰（#6B7280）

### 字体和字号
- **标题**：11pt，加粗
- **正文**：10pt
- **输入框**：10pt
- **按钮**：10pt，主要按钮13pt
- **日志**：等宽字体（Consolas），10pt

### 间距规范
- **全局间距**：16px
- **卡片内边距**：14px
- **元素间距**：10px
- **按钮间距**：12px

## 交互设计

### 输入框
- 获得焦点时边框变蓝（#0078D4）
- 悬停时边框变蓝
- 禁用状态：灰色背景和边框

### 按钮
- 悬停时边框变蓝，背景变浅
- 按下时背景变深
- 禁用状态：灰色背景和文字

### 复选框
- 自定义SVG样式
- 选中时绿色背景（#0EA348）
- 未选中时白色背景，灰色边框

### 下拉框
- 圆角样式
- 弹出层透明背景
- 选中项蓝色背景

## 动画效果

### 进度条
- 流光动画效果
- 动画间隔：100ms
- 流光宽度：100px

### 状态切换
- 平滑过渡：150ms
- 使用ease-in-out缓动函数

## 响应式设计

### 窗口尺寸
- **最小尺寸**：800×600
- **默认尺寸**：1000×750
- **最大尺寸**：无限制

### 区域比例
- **左侧区域**：最小宽度350px，占40%
- **右侧区域**：最小宽度400px，占60%
- **窗口缩放时**：左右区域按比例调整

## 无障碍设计

### 对比度
- 文字与背景对比度≥4.5:1
- 重要元素对比度≥7:1

### 焦点状态
- 所有交互元素有明显焦点指示
- 焦点环颜色：蓝色（#0078D4）

### 键盘导航
- Tab顺序符合逻辑
- 支持快捷键操作

## 技术实现

### 技术栈
- **框架**：PySide6 (Qt 6.11.0)
- **Python版本**：3.13.13
- **布局管理**：QHBoxLayout, QVBoxLayout, QGridLayout, QScrollArea
- **样式**：QSS (Qt Style Sheets)

### 关键组件
1. **DragLineEdit**：支持拖拽的输入框
2. **RoundComboBox**：圆角下拉框
3. **AnimatedProgressBar**：带流光效果的进度条

### 文件结构
```
ui/

├── styles.py         # QSS样式
├── widgets.py        # 自定义控件
└── workers.py        # 工作线程
```
